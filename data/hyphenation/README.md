# Hyphenation patterns

`hyph-en-us.pat.txt` and `hyph-en-us.hyp.txt` are the American English
hyphenation patterns and exceptions from the
[hyph-utf8](https://www.hyphenation.org/tex) package, unchanged. omaquill's
PDF Compile uses them (see `src/hyphen.rs`) to hyphenate the paperback
layout.
